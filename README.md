# 🛡️ Phishing Awareness Training

## Protecting Users from Social Engineering Attacks

---

## 📖 Project Overview

This project is a **Phishing Awareness Training presentation** developed as part of a **Cybersecurity Internship**.  
The goal of the project is to educate users on how phishing attacks work, how attackers use social engineering techniques, and how individuals and organizations can reduce risk through awareness and best practices.

Phishing remains one of the **most common initial attack vectors** used in:
- Account compromise
- Data breaches
- Ransomware attacks
- Corporate network intrusions

This training focuses on the **human layer of security**, emphasizing prevention through user education.

---

## 🎯 Objectives

The training aims to:
- Explain what phishing is and why it is dangerous
- Identify common phishing attack types
- Teach users how to recognize phishing emails and fake websites
- Demonstrate social engineering techniques used by attackers
- Provide actionable best practices for prevention
- Encourage early reporting of suspicious activity

---

## 🧩 Topics Covered

The presentation includes the following sections:

- Introduction to Phishing
- Why Phishing Is Dangerous
- Common Types of Phishing Attacks
  - Email phishing
  - Spear phishing
  - Whaling
  - Smishing
  - Vishing
- How to Recognize Phishing Emails
- Identifying Fake Websites
- Social Engineering Tactics
- Best Practices for Prevention
- Real-World Phishing Example
- Interactive Quiz & Scenario-Based Questions
- Key Security Takeaways
